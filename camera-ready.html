Required format

One PDF, NeurIPS 2026 structure

We only accept camera-ready papers that follow the NeurIPS 2026 camera-ready structure. Everything is combined into a single PDF, in this order:

  1. Main paper — the paper content, de-anonymized with author names and affiliations
  2. References
  3. Appendices — any other supporting text, e.g. proofs and experimental details
  4. NeurIPS paper checklist

References, appendices, and the checklist do not count toward the page limit. Code and data should not be placed in the PDF.

Checklist

Before you upload

  • NeurIPS 2026 LaTeX style file only, using the camera-ready (final) option
  • No changes to margins, font sizes, or spacing
  • Paper de-anonymized for the camera-ready version
  • Main paper updated in response to reviewer comments
  • NeurIPS paper checklist included at the end
  • Single PDF, maximum file size 50MB
  • All authors' OpenReview profiles up to date (see registration)

Formatting requirement

NeurIPS 2026 style

Use the NeurIPS 2026 LaTeX style file, available from the NeurIPS 2026 Call for Papers page. It is the only template we accept. Papers that change the style or exceed the page limit may not be included in the workshop program.

Attending NeurIPS

Registration for Accepted Papers

Reserved slot

One registration per accepted paper

Following the NeurIPS 2026 multi-site registration process, each accepted workshop paper receives one reserved registration allocation for its authors. The reservation is tied to the site where the workshop takes place: Sydney, Australia.

We will import all accepted papers into the NeurIPS website with the author information from OpenReview. The reserved registration applies only once the paper has been linked to the authors' NeurIPS accounts, so authors should register using the same information they have in OpenReview.

Other co-authors register as part of the general public. General registration is first-come, first-served, with a waiting list for each location, so we strongly recommend registering as early as possible.

What authors need to do

Before registering

  • Keep your OpenReview profile up to date, especially your name and email
  • Make sure the author list in your camera-ready revision is final
  • Register on the NeurIPS website with the same information as in OpenReview
  • Co-authors not using the reserved slot should register early as general public

Official details

NeurIPS 2026 registration

For all registration questions, including allocations, deadlines, refunds, and waiting lists, please refer to the NeurIPS blog post Navigating NeurIPS 2026: A Breakdown of the Multi-Site Registration Process. Registration is handled by NeurIPS, not by the workshop organizers.
